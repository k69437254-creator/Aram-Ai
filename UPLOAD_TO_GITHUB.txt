ARAM AI 0.2.0 — تحديث مستودع GitHub من Termux

هذا الأرشيف تحديث كامل للمصدر، لكنه لا يحتوي مجلد .git حتى لا يستبدل تاريخ المستودع الحالي.

1) فك ضغط محتويات الأرشيف مباشرة داخل ~/AramAI مع اختيار دمج/استبدال الملفات. لا تحذف مجلد .git المخفي.
2) افتح Termux ونفّذ:

   cd ~/AramAI
   bash PUSH_UPDATE.sh

3) السكربت يتحقق من المستودع والفرع وعنوان origin، ويفحص ملفات XML وGradle والسكربتات، ثم ينشئ commit ويرفعه إلى main.
4) افتح GitHub → Actions → Build Aram AI APK. بعد نجاح البناء نزّل artifact باسم Aram-AI-ARM64-debug-APK.

مهم:
- استخدم PUSH_UPDATE.sh للتحديث الحالي.
- لا تستخدم UPLOAD_TO_GITHUB.sh؛ فهو مخصص لمستودع فارغ جديد فقط.
- لا تحذف ~/.git ولا تنفذ git init أو force-push.
- ملف النموذج GGUF لا يدخل في ZIP أو APK؛ يبقى محفوظًا داخل بيانات التطبيق على الهاتف.
- لا ترسل مفاتيح API أو رموز GitHub إلى المحادثة.
